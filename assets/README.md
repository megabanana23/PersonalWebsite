# Image organization

Keep new images in the folder that matches their purpose:

- `profile/` — portrait and personal profile images
- `projects/` — project logos, screenshots, and graphics
- `events/scratch-coding/` — Scratch Coding Workshop photos
- `events/lego-bridge/` — LEGO Bridge Building Workshop photos
- `events/light-and-sound/` — Light and Sound Workshop photos

Use short, lowercase filenames with hyphens, such as `students-testing-bridge.jpg`.
When adding a workshop photo to the website, place it in the matching event folder and
add an `<img>` entry to that workshop's photo carousel in `index.html`.

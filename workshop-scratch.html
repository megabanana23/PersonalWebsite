SCRATCH Coding Workshop

A beginner-friendly introduction to programming through interactive stories, games, and animations.

Workshop overview

Learn and apply coding skills.

Students will learn coding fundamentals with Scratch, MIT's free block-based visual programming tool. Participants should bring a laptop when possible; the library has a limited number available to borrow.

Students will explore

  • Loops, variables, events, and logical thinking
  • Interactive stories and animations
  • Simple game design and creative problem-solving
